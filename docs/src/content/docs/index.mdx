## What is IndusBase?

IndusBase is a self-hosted, open-source Backend-as-a-Service built specifically for the Indian market.
It gives your app a Postgres database, authentication, realtime subscriptions, file storage, edge
functions, AI vector search, job queues, and push notifications — all behind a single API gateway.

## Architecture at a Glance

| Service | Language | Port | Purpose |
|---------|----------|------|---------|
| indus-gate | Zig 0.14 | 8000 | API Gateway |
| indus-auth | Go 1.23 | 8001 | Auth + WhatsApp OTP + Aadhaar |
| indus-query | Rust 2021 | 8002 | Auto REST + GraphQL from PostgreSQL |
| indus-live | Gleam 1.10 | 8004 | Realtime WebSocket |
| indus-store | Go 1.23 | 8005 | S3-compatible object storage |
| indus-edge | Zig 0.14 | 8006 | Edge functions (Bun workers) |
| indus-ai | Rust 2021 | 8007 | Vector search + embeddings |
| indus-queue | Go 1.23 | 8008 | Job queue + webhooks + cron |
| indus-notify | Go 1.23 | 8009 | Push + SMS + Email notifications |
| indus-config | Go 1.23 | 8010 | Feature flags + remote config |

## Quick Start

```bash
git clone https://github.com/indusbase/indusbase
cd indusbase
cp .env.example .env
openssl genrsa -out jwt-private.pem 2048
openssl rsa -in jwt-private.pem -pubout -out jwt-public.pem
docker-compose up -d --build
sleep 30 && curl http://localhost:8000/health | jq
```

Your IndusBase is now running at [**http://localhost:8000**](http://localhost:8000).
Open the dashboard at [**http://localhost:3000**](http://localhost:3000).
