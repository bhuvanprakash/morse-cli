title: Responsible Disclosure
description: How to report security issues to IndusBase.
---

## Report a Security Issue

Please report vulnerabilities privately:

- Email: `security@indusbase.com`
- Subject: `Security Disclosure - IndusBase`

Include:

- affected component/service
- reproduction steps
- impact assessment
- proof-of-concept (if available)

## Disclosure Process

1. Acknowledge receipt within 2 business days.
2. Validate and triage severity.
3. Ship mitigation/fix and communicate timeline.
4. Publish advisory/postmortem when appropriate.
