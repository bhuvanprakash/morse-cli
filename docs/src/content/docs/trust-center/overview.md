# Trust Center

IndusBase Trust Center provides a public summary of our security and compliance posture.

## Security Principles

- Secure-by-default service architecture
- Least-privilege internal access using `X-IndusBase-Internal`
- Structured JSON logging and audit trails
- Encryption in transit (TLS) and encryption at rest

## Data Residency

India-first defaults:

- Region: `ap-south-1`
- Timezone: `Asia/Kolkata`
- Currency examples: `INR / Rs.`

## Reliability

- Automated backups and restore drills
- Incident response workflow with postmortems
- Health checks and `/metrics` for all services

- Status page: `/status`
